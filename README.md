## Project Overview

RS Labs bridges the gap between material science and athletic performance. This 5-page website showcases the brand's engineered apparel line, history, multi-location physical operations, and inquiry systems for customers and wholesale partners.

## Features & Functionality

* **Semantic HTML5:** Built using structured, accessible HTML elements (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`).
* **Responsive Layout:** Adaptive design using CSS Grid and Flexbox for seamless viewing across desktop, tablet, and mobile screens.
* **Global Navigation:** Consistent top navigation bar embedded across all 5 HTML files for effortless site-wide access.
* **Multi-Location Integration:** Embedded Google Maps on the Contact page showcasing both the USA R&D Facility and the UK Distribution Centre.
* **Interactive Forms:** Dedicated forms for product inquiries and direct support messages.

---

## Technologies Used

* **HTML5:** Semantic markup and site structure.
* **CSS3:** Custom styling, CSS Grid, Flexbox, media queries, and root variables.
* **JavaScript (ES6):** Client-side scripting setup (`js/main.js`).

## Setup & Usage Instructions

1. **Clone or Download:** Save the project folder `rs-labs` to your local machine.
2. **Directory Verification:** Ensure all `.html` files sit in the root folder alongside the `css/`, `js/`, and `images/` directories.
3. **Run Locally:** Double-click `index.html` or open it directly in any modern web browser.
4. **Development Live Server (Optional):** Open the project folder in VS Code and launch with the **Live Server** extension.

## Browser Compatibility & Testing

The website has been tested across major modern web browsers to ensure rendering consistency, flexbox alignment, and responsive breakpoint behavior:
